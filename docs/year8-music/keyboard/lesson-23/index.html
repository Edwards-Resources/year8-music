Lesson 23: Keyboard Challenges

Lesson 23 of 25, in Test and Beyond.

Learning intention

We are learning to celebrate our skills through challenges.

Success criteria

Tick them off as you go.

LearnThe test is done.

Three lessons left and no assessment in any of them. Today is skill games: the same things you have been practising all term, played against a clock and against each other.

Step by stepThe four challenges

  1. Scale sprint: C major, one octave up and down, cleanly, as fast as you can hold it together.
  2. Note name relay: your teacher points at a key, first correct name takes the point.
  3. Contour call: hear four notes, name the shape before anyone else does.
  4. No mistakes: play Hot Cross Buns four times in a row. One wrong note and you start again.

Your task

Rotate through all four challenges in teams and keep score. The scale sprint is the one worth practising between rounds, because speed without accuracy scores nothing.

Need a hand?Accuracy beats speed

Every one of these gives the point to the clean answer, not the fast one. Playing at half speed with no mistakes wins more rounds than rushing does.

Go further

Set the challenge for the next round. Design a fifth game, explain the rules, and run it for your group.

Exit ticket

Which challenge did your team do best at?
