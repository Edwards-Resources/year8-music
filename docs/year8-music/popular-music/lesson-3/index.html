Getting started in GarageBand for iPad

Set up your project - follow along

  1. Open GarageBand and choose Empty Project.
  2. When asked to choose a track type, select Software Instrument.
  3. Find the tempo in the display at the top of the window. Set it to 100 bpm.
  4. Turn on the metronome. Press play and listen to the click.
  5. Turn on the count-in so you get one bar of clicks before recording starts.
  6. Save now: File → Save As. Name it Surname_PopularMusic and save to your student drive, not the desktop.

Save it properly, once

This is the project you build on all term and submit in Week 8. If it lives on the desktop of a shared machine, you will lose it.

Key word: Loop

A repeated musical phrase recorded and layered digitally. Most popular music is built from loops stacked on top of each other.

Stuck? Common problems

I can't hear the click. Check the metronome icon is highlighted, and that your headphones are plugged in properly. I can't find the tempo. It is the number in the display at the top centre. Click and drag it up or down. Nothing happens when I press record. Make sure a track is selected - it should be highlighted on the left.

Go further

Import a reference track of an Australian song you like. Work out its tempo by ear, then set your project tempo to match so the grid lines up with the song.
