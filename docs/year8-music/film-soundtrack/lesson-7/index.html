Star Wars (Main Theme)

The first great movie score.

King Kong (1933) is usually credited as the first film built on a full symphonic score made from recurring themes - one for Kong, another for the ship, another for danger. Four decades later, Star Wars did the same thing for Vader, the rebels and the Force, using the same trick Max Steiner pioneered.

Key word: Leitmotif

A recurring musical theme that represents a character, place, idea or emotion. It can change key, tempo or instrumentation and still be recognisable.
